# Shopify Beauty Storefront Theme

This repository contains a beauty storefront built on Shopify's Horizon theme (version 4.1.5). The home page uses custom sections for a campaign hero, editorial feature, product collections, a brand spotlight, and category links.

## What's in the theme

- `templates/index.json` sets the home page sections, content, and order.
- `sections/` and `blocks/` contain the editable page components.
- `assets/` contains the theme styles, scripts, and editorial imagery.
- `config/` contains theme settings and their current values.
- `layout/`, `snippets/`, and `locales/` support the rest of the storefront.

The home page refers to sample product handles and tag-based search links. Some category images are loaded from external Unsplash URLs.

This repository tracks the theme source. Store products, orders, and other Shopify admin data are managed separately.
